## 一、结论摘要

- **首选（个股）**：东方财富两条 JSON 通道 —— ①新闻搜索（个股新闻，100 条/页）②研报接口（600519 有 225 篇）。
- **次选（个股）**：腾讯自选股个股新闻 JSON（无签名；分 type=1/0 两路）。
- **公告/问答（官方）**：东财公告 + 巨潮公告（两步：代码→orgId）+ 深交所互动易（POST，全库 6.9 万条）。
- **快讯（全市场）**：财联社、东财 7x24、新浪 7x24、华尔街见闻、金十、富途、同花顺直播——全部实测可用。
- **天眼查（用户点名）**：可达但为工商/股权/风险信息，**非新闻通道**；详情页预计登录墙，新闻需求不用它。
- **放弃**：雪球（WAF+登录态）、百度资讯（验证码）、企查查（JS 加密体）；同花顺 F10/新浪个股页需 JS 渲染（已有等价源，优先级低）。

## 三、关键参数样例（踩坑备忘）

**财联社签名**（顺序写反会 10012 签名错误）：
```python
params = {"app": "CailianpressWeb", "category": "", "last_time": str(int(time.time())),
          "os": "web", "refresh_type": "1", "rn": "20", "sv": "8.4.6"}
sign = md5(sha1(urlencode(params)).hexdigest()).hexdigest()   # 注意：先 sha1 再 md5
```

**东财新闻搜索**：`param={"uid":"","keyword":"600519","type":["cmsArticleWebOld"],...,
{"searchScope":"default","sort":"time","pageIndex":1,"pageSize":100}}`；建议 Referer `https://so.eastmoney.com/`。
keyword 用 6 位代码（600 hits）或名称（贵州茅台 4534 hits，含泛关联需再筛）。

**巨潮公告两步**：① POST `new/information/topSearch/query` keyWord=600519 → orgId=gssh0600519；
② POST `new/hisAnnouncement/query` `stock=600519,gssh0600519&column=sse&tabName=fulltext&pageSize=...`（深市 column=szse）。

**腾讯个股新闻**：`symbol=sh600519&page=1&n=20&type=1`。

## 四、历史深度（能否回填到 2020-01-01？）

**能。** 多条通道"直跳"到 2020-01-01 当天均取到数据：

| 源 | 档案起点 | 回填机制 | 回填量估算 |
|---|---|---|---|
| 财联社电报 | ≈2015 | `last_time`=任意时间戳链式回溯 | ~300 条/日；rn=50 → ~1.5 万请求（1~2h） |
| 东财 7x24 | ≈2016 | `sortEnd`=微秒时间戳链式 | pageSize=200 → ~5k 请求（0.5~1h） |
| 东财公告 | 个股到 2007+ | 逐股翻页 | 逐股 ~10-25 页 |
| 巨潮公告 | ≤2010 | `seDate` 窗口 + **全市场按日批量** | 2020-01-02 一天全市场 1792 条；~4-5 万请求全量 |
| 东财研报 | ≈2017 | 窗口扫描 | 按季 ~30 窗口 → 十几分钟 |
| 腾讯个股新闻 | ≥2019-09 | 逐股翻页 | 每只 300-560 页（适合票池） |

**快讯条目自带标签（关键发现）**：东财 7x24 `stockList` 2020 年样本 200 条中 **87 条带个股代码**
（`1.600036` 格式）+ 60 条带板块（`90.BK`）；财联社 `stock_list` 稀疏（~8%）、subjects 丰富
→ **全市场快讯回填 = 个股新闻时间线自动挂接**。

**不能到 2020 的**：东财新闻搜索（≤1000 条窗口）、新浪 7x24（~2 天）、金十（max_time 被忽略）、
同花顺 F10/新浪个股页（JS）、互动易（接口日期参数待打通）、股吧（f_1000 至 2025-12）。

## 六、机制与修复

- **游标链式回溯 + `_state.json` 断点 + 日文件按 id/code 去重合并**；失败 6 次退避。
- **state 兜底 `rebuild_state_from_files()`**：`_state.json` 丢失时按日文件覆盖重建游标
  （newest/oldest + 空洞检测 + done=文件已覆盖下界），避免整段重爬数小时。E2E 已验证
  （备份→删 state→跑 1 请求→重建续传正常→恢复）。
- **接口纪律（用户 2026-09-25 指令，已入全局规范）**：凡区间/分页接口必须先查本地状态、只请求缺失区间。
- 榜单/行情侧同日补齐：6 个 scrap 脚本统一无参 `is_latest()`（dietingban/zhangtingban=扫 `{date}涨跌停板.xlsx`；
  longhu=日 json；kaipanla=saved_dates()；news=最新日文件≥目标日）；quick_kline `_scan_isst` 只补缺失段
  （返回语义修正为"全区间覆盖子集"）；news/榜单均已挂入 `update_all.py` 每日链。
