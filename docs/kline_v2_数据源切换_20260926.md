# K线数据源 v2 切换与旧库撤除（2026-09-26）

## 背景

旧日线库 `dataset/kline_data/daily_kline/` 为 baostock 前复权序列，存在结构性缺陷：

1. **锚点漂移**：历史段停在最后一次全量刷新点。2026 年除权因子整体缺失（样本 494 个缺失边界中 493 个在 2026），对 2026 除权股的历史序列是"假跳空"（如 sh.688332 缺 0.665 因子 → 全史差 33%）。
2. **送转事件因子偏高 0.3~0.9%**（破坏市值守恒）。实证：sz.300723 2021-04-29 10转8派0.25，旧库隐含参考价 28.16，正确值 (50.50−0.25)/1.8 = 27.92（180×27.92 = 5025.6 ≈ 5050−25 ✓）。
3. `preclose` 列实为"昨收移位拷贝"，非官方除权参考价。

## v2 结构

- `dataset/kline_data/daily_kline_v2/<code>.csv`：**未复权原值** 13 列
  （`date,code,open,high,low,close,preclose,volume,amount,turn,tradestatus,pctChg,isST`）。
  真实行 `tradestatus=1`；停牌占位行 `tradestatus=0`（价格列=carry，volume=0；turn/pctChg 为空）。
- `dataset/kline_data/_aux/`：`adjust_factors.parquet`（扶摇事件抖动）、股本事件、`delisted.parquet`（退市表）、isST parquet、名称/meta 缓存。
- **复权在读取时进行**（`utils/kline_data_utils/kline_v2_reader.py`）：
  - `read_daily(code, 'qfq'|'raw')` → 13 列 DataFrame（与旧库同构）
  - `close_rows(code)` → `[(date, qfq_close), ...]`（轻量解析，~2ms/只）
  - 因子边界**全部由 v2 自带 preclose（官方除权参考价）推导**：真实行相邻过渡处 `preclose[r] ≠ close[前一真实行]` 即一次除权，`f = preclose/前收`；停牌期间除权在**复牌行**一次性生效。非事件日 preclose 严格==昨收（758 万行仅 23 行例外，均为停牌跨除权个案）。

## 验证结论（2026-09-25/26）

- 全市场 5222 只 / 758 万行：相邻行连续性检查 **0 超差**（除权处序列严格连续）。
- 特征级对拍（40 无事件 + 40 有 2026 事件）：无事件组 close 逐位一致（p50/p90 = 0，max 4.7e-07）；有事件组差异 = 旧库缺因子修正。
- m15：特征（rsi14/kdj）只用 close/high/low，**volume/amount 不参与**；新浪增量与库内历史差异局限于孤立"接缝日"（价格 ≤0.5% 典型）。
